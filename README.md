# 📘 Youth Lyceum (Молодіжний Ліцей) - Website Project

**Live Demo:** [https://molodizhnelyceum.pythonanywhere.com/](https://molodizhnelyceum.pythonanywhere.com/)

This project is a website developed for the Youth Lyceum as a practical demonstration of my skills in web development. The goal was to create a modern, clean, and easily navigable platform that provides essential information for students, parents, and faculty.

Mobile adapted!
